# 食物管理体验优化实施计划

目标：完成决策清单 1、2、3、4、5、8、9、11。

顺序：业务语义与兼容数据 → 库存操作 → 首页和识别核对 → 设置分组 → 构建及真机验收。

1. 状态统一为未临期、未设置到期日，主题提供可读语义色，状态字号提升。
2. Room v9 添加 quantitySpecified；旧零数量保持未知，明确输入零可表达用完。直接编辑余量支持小数；写入确认后反馈。
3. 卡片保留余量、编辑和更多，永久删除确认；归档成功后提供撤销。
4. 首页待处理清单前置，统计点击带状态筛选进入库存。
5. 识别草稿去掉概率化表达，明确缺失字段、日期核对和来源，保留手工修正。
6. 设置诊断折叠，数据与隐私保留归档及记录管理。
7. 扩展迁移和数量测试，构建单测与 Lint；独立 validation 包进行页面重建、返回、归档撤销、筛选及通知验收。不覆盖用户安装包。没有设备证据的场景单独列为待验收。

方案取舍：保留现有 Compose 与单模块架构、品牌色和离线定位；选择局部重排和语义完善，不扩展到整套导航重写。用户已授权自主排序与实施，不另设设计确认步骤。
