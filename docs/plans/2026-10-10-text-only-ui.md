# 无图工具风格 UI 改造

依据用户确认的无图首页、展开录入表单和位置面板效果图执行；不依赖食品图片，不新增网络服务，不修改识别、保存、数据库和日期规则。

1. 统一浅灰背景、白色内容区、绿色主操作、橙色待核对、红色过期及错误；调整中文字号、圆角及 16dp 页边距。
2. 首页收紧标题与库存概览，绿色录入入口，浅色搜索；四项固定状态切换，其他状态放进更多筛选；位置保持固定高度入口。无图食物行突出名称和剩余时间，数量、位置及分类日期弱化。
3. 录入方式收成四项切换，原文框保持可编辑并限制可见行数，重新识别及清空逻辑保留。核心六项常驻展开，横向标签与直接输入，数量单位同排；普通字段不再重复显示来源，疑问字段与候选使用橙色提示。常用位置从无限标签变为按需选择，直接编辑能力保留。
4. 可选信息与常买食品沿用独立入口，底部常驻保存及单次确认保持；主页面继续统一处理键盘和系统边距。
5. 选择面板沿用共用安全区容器，位置排序换成紧凑三段切换；单位、分类、日期、常买食品与管理页面统一视觉。
6. 用户已要求不运行测试：只构建 Debug 安装包、检查代码差异格式；手机可连接时覆盖更新，否则交付安装包，不声称完成真机验收。

## 交付结果

上述改造已完成，核心表单使用紧凑的横向标签与直接编辑；数量单位同排，位置可自由输入并从独立面板选择常用值，日期区分到期与食用计划文案。照片、文字、手动、按住说话与重新识别仍沿用现有处理；原文保持展开且最多显示三行。保存持续显示在独立底部区域，校验及单次确认流程未改。

首页保留食用计划、需处理、归档和清除筛选路径，食物列表不使用图片或占位图片；正常状态绿色、临期橙色、过期红色。字号、边距、圆角、搜索和模式控件在录入、选择面板、位置管理及设置中统一。

最终 Debug 构建成功，改动文件差异格式检查通过。无线调试已恢复，新安装包覆盖原应用成功（applicationId 与应用名称保持），手机数据保留。按用户要求未运行 JVM、真机或 lint 测试；未对实际布局和大字体效果作验收声明，由用户试用。

## 圆形按住说话按钮

后续按截图反馈将语音入口改为居中的 88dp 圆形麦克风，使用固定 112dp 手势区域，动画不改变取消边界。按下立即缩至 92% 并轻微加深颜色，松手或取消后弹簧回弹；录音时显示呼吸光环，准备时显示加载环，下方文字保留状态提示。呼吸动画仅在录音且准备结束时运行，无录音时不持续播放。沿用按住开始、松手结束、移出取消和无障碍开始/结束语义，不改变语音模型及解析流程。

本次 Debug 构建与差异格式检查通过，按用户要求未运行测试。手机无线调试断开，暂未覆盖安装，本次安装包供用户自行试用。
