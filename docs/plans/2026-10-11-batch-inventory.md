# 批量库存操作实施计划

目标：仅执行第 6 项，食品和物品主列表长按多选，批量移动位置、归档、恢复、确认后删除。

架构：共用多选布局与操作确认组件；Repository 事务内校验所有记录的类型和归档状态，然后整体提交。沿用现有提醒与附件清理，不增加数据库版本。

1. InventoryRecordCard 增加长按与多选状态，选择中点击卡片只切换选中，隐藏单条菜单。
2. InventoryBatchLayout 提供固定选择栏、当前结果全选、退出和底部操作栏；筛选变化清空选择，返回先退出多选。
3. ItemRepository / HouseholdViewModel 增加事务式批量操作；缺失或状态已变化的记录导致整体失败；失败保留选择和错误信息。
4. 食品和物品主列表接入共享组件。移动位置可自由编辑及选择少量常用位置；归档、恢复、删除均显示数量确认。
5. 验证边界与事务回滚、本地回归、构建；覆盖更新原应用，不操作用户库存。新增测试代码继续排除在 Git 外。

验证：离线构建通过，本地测试 205 项、失败 0 项。新增用例涵盖重复/缺失/错类型选择、归档状态变化、恢复与归档边界、自由地点与显式别名、选择快照隔离。另以当前 Room schema 和实际 DAO SQL 验证整批移动/归档/恢复、第二条失败回滚、未选择记录隔离、删除附件与提醒级联清理。未在用户库存上执行批量修改或删除。
